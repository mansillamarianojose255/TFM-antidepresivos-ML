# LDlink / LDmatrix / LDhap

Este directorio puede utilizarse para conservar las exportaciones de la plataforma LDlink empleadas en el TFM.

Parámetros metodológicos:

- ensamblado: GRCh37;
- población de referencia: FIN (Finnish in Finland);
- LDmatrix: matrices de r² y D′;
- análisis inicial: rs1612063, rs2857702, rs140872668, rs2858877, rs2071536, rs115493740, rs3749981, rs241407 y rs114463908;
- grupo de cinco variantes con mayor LD: rs2071536, rs115493740, rs3749981, rs241407 y rs114463908;
- LDhap: las mismas cinco variantes, población FIN.

Estos resultados corresponden al panel de referencia de 1000 Genomes utilizado por LDlink y no deben describirse como una reconstrucción directa del LD de FinnGen.
